DOCUMENTACIÓN FUNCIONAL DEL PROYECTO TECH-JUANJO
===============================================

Objetivo del documento
----------------------
Este documento resume las funcionalidades visibles del proyecto, historias de usuario y una guía de pruebas manuales para validar el sistema punto por punto.

Resumen del proyecto
--------------------
TECH-JUANJO es una aplicación web desarrollada en Django para la gestión y venta de productos tecnológicos. El sistema está dividido por módulos principales:

1. Gestión de usuarios
2. Catálogo de productos
3. Carrito de compras
4. Pedidos
5. Panel administrativo propio

Rutas principales del sistema
-----------------------------
Rutas base identificadas en el proyecto:

- `/` → Inicio / Home
- `/catalogo/` → Listado de productos
- `/usuarios/login/` → Inicio de sesión
- `/usuarios/registro/` → Registro de usuarios
- `/usuarios/dashboard/` → Dashboard de usuario
- `/usuarios/dashboard-admin/` → Dashboard administrativo
- `/carrito/` → Carrito
- `/carrito/checkout/` → Checkout
- `/pedidos/mis-pedidos/` → Historial de pedidos del usuario

MÓDULO 1: USUARIOS
==================

Funcionalidades identificadas
-----------------------------
Según las vistas, formularios, modelos y rutas del módulo `usuarios`, el sistema soporta:

1. Inicio de sesión
   - Ruta: `/usuarios/login/`
   - Permite autenticar usuarios del sistema.

2. Registro de usuarios
   - Ruta: `/usuarios/registro/`
   - Permite crear nuevas cuentas.

3. Cierre de sesión
   - Ruta: `/usuarios/logout/`

4. Dashboard por usuario
   - Ruta: `/usuarios/dashboard/`
   - Redirección o experiencia según rol del usuario.

5. Dashboard administrativo
   - Ruta: `/usuarios/dashboard-admin/`
   - Vista administrativa personalizada diferente al admin nativo de Django.

6. Perfil de usuario
   - Ruta: `/usuarios/perfil/`

7. Edición de datos del usuario autenticado
   - Ruta: `/usuarios/editar/`

8. Cambio de contraseña
   - Ruta: `/usuarios/cambiar-password/`

9. Cambio de correo electrónico
   - Ruta: `/usuarios/cambiar-email/`

10. Confirmación de cambio de correo por token
    - Ruta: `/usuarios/confirm-email/<token>/`

11. Listado administrativo de usuarios
    - Ruta: `/usuarios/lista-usuarios/`

12. Creación administrativa de usuarios
    - Ruta: `/usuarios/crear-usuario/`

13. Edición administrativa de usuarios
    - Ruta: `/usuarios/editar-usuario/<pk>/`

14. Desactivación administrativa de usuarios
    - Ruta: `/usuarios/desactivar-usuario/<pk>/`

15. Eliminación administrativa de usuarios
    - Ruta: `/usuarios/eliminar-usuario/<pk>/`

16. Control de acceso por rol
    - Existen decoradores para:
      - admin
      - usuario normal
      - múltiples roles

17. Seguridad de acceso
    - Existe evidencia de:
      - validación de contraseña anterior
      - tokens para procesos sensibles

18. Roles de usuario
    - Se evidencian al menos estos roles:
      - admin
      - cliente /comprador

MÓDULO 2: CATÁLOGO
==================

Funcionalidades identificadas
-----------------------------
Según las rutas, modelos, formularios, vistas y plantillas revisadas, el módulo de catálogo soporta:

1. Home pública
   - Ruta: `/`
   - Muestra productos destacados.
   - Muestra productos del catálogo.
   - Tiene secciones promocionales e indicadores de confianza.

2. Listado público de productos
   - Ruta: `/catalogo/`

3. Filtros de productos en catálogo
   - Por categoría
   - Por marca
   - Por condición
   - Por precio mínimo
   - Por precio máximo
   - Por búsqueda de texto

4. Detalle de producto
   - Ruta: `/catalogo/<slug>/`

5. Creación de productos por admin
   - Ruta: `/catalogo/crear/`

6. Edición de productos por admin
   - Ruta: `/catalogo/<slug>/editar/`

7. Eliminación de productos por admin
   - Ruta: `/catalogo/<slug>/eliminar/`

8. Gestión de categorías
   - Listado: `/category/`
   - Crear: `/category/crear/`
   - Editar: `/category/<slug>/editar/`

9. Gestión de marcas
   - Listado: `/brand/`
   - Crear: `/brand/crear/`
   - Editar: `/brand/<slug>/editar/`

10. Creación rápida de categoría desde el formulario de producto
    - El admin puede escribir una nueva categoría si no existe.

11. Creación rápida de marca desde el formulario de producto
    - El admin puede escribir una nueva marca si no existe.

12. Productos destacados
    - Existe el campo `destacado`.
    - El admin puede marcar productos para la sección de destacados.

13. Control de visibilidad por estado
    - Existe el campo `activo`.
    - El catálogo público trabaja sobre productos activos.

14. Slug automático por nombre
    - El sistema genera slug automáticamente desde el nombre del producto.

15. Formato visual mejorado en home
    - Se hicieron ajustes responsive.
    - Los precios en home están formateados con separadores de miles.
